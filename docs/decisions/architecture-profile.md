# Architecture Profile

**Profile B: Google AI Studio full-stack Web app**

- **Client**: React and TypeScript
- **Server**: Express (Google AI Studio full-stack Node.js runtime)
- **Deployment**: Cloud Run
- **Operational Database**: Firestore
- **Object Storage**: Google Cloud Storage / Firebase Storage
- **Background Processing**: Cloud Tasks / Pub/Sub
- **Scheduled Work**: Cloud Scheduler
- **Secrets**: Google AI Studio Secrets (dev), Google Cloud Secrets (prod)
